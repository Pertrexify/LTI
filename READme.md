## PROJECT NAME: Circular Garden Calculator

## Description
* calculates the Area of a circle for the Garden based off the Radius the user inputs

## How to Run:
* Just input any Radius and the program shows results to: Area, Circumference, Square Root of area,
  and the round up/down to the nearest whole number

## Input Needed
* Any Radius

## Sample output
* User enters a radius: 
# Radius : 24.6

# =========================
* Your area is: 605.16
* Circumference:, 77.28
* Square Root of Area:, 24.60
* Area Rounded Down: 605
* Area Rounded Up: 606 
# =========================
